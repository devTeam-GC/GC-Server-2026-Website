Что сделать, чтобы начать играть?

  1. Установить один из лаунчеров


    GC Launcher (поддержка Ely.by и нелицензионных аккаунтов)
    Только для Windows
    Prism Launcher (версия 11 и выше)    		 Любой лаунчер на основе Prism Launcher версии 11 и выше…

  2. Нажать на кнопку ниже

    Установить игровую сборку

    После нажатия должен открыться лаунчер и предложить установить сборку в него.

Если не появится лаунчер после нажатия, попробуйте использовать не portable версию лаунчера (версия без установки), либо установить лаунчер вручную по ссылке ниже:
